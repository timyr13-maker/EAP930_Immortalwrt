# Stock Firmware Files

These files were extracted from the original Netis EAP930 firmware for analysis and comparison purposes.

## Source Information
- **Manufacturer**: Netis
- **Model**: EAP930
- **Hardware Version**: V1.0
- **Base OS**: MediaTek SDK (based on OpenWrt 21.02)
- **Extraction Method**: Files were extracted from a binary firmware dump using `binwalk` and `ubi-reader`.

## Purpose
- Verifying LED GPIO assignments.
- Verifying button GPIO assignments.
- Analyzing stock partition layout.
- Comparing default UCI configurations.
